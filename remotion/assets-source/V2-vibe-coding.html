Vibe Coding · The Review Ritual
Step 4 — The Review
You are the QA.
Every time.
The loop only works if you actually look
📸
Take screenshots of every change
Full page, not just the changed section. Context matters.
✏️
Annotate directly on the screenshot
Circle the problem. Draw the arrow. Mark what's wrong.
📤
Paste the screenshot back to Claude
It sees what you see. Explain the correction. It fixes it precisely.
✅
If it passes — commit it
One commit. One feature. Clean git history. Back to STATE.md.
🔁
If it fails — loop again
Never batch the fix with something else. One problem, one fix, one commit.
