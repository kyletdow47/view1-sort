QA Process · Build Loop
The Automated QA Loop
Claude checks Claude — then humans verify
🤖
Build Agent (Sonnet)
Builds Feature
Picks up P0 Asana task. Reads codebase. Writes real files. One task, one commit. No batching.
📤
Automated
Moves to Code Review
Build agent marks task complete. Creates a new QA task. Assigns to the visual QA agent.
👁️
QA Agent (Sonnet)
Visual Review
Takes screenshots. Checks the build against the spec. Tests the UI. Identifies any issues.
✅
Pass → Close
❌
Fail → New task
🔁
Loop
Repeat Until Pass
Failed tasks go back to the build agent. Max 3 attempts. If blocked, human reviews.

QA System · 3-Attempt Retry Pattern
How Quality Compound
Pass. Pass. Blocked.
Fix. Pass.
The QA agent runs until it passes or escalates
🔍
Attempt 1
QA Agent reviews the build
Visual scan. Functionality check. Does it match the spec?
✅
Pass
Task marked complete in Asana
Moves to "Done". Next task picked up automatically.
🚫
Blocked
Creates a new fix task in Asana
Comments what failed. Sends back to build agent with exact instructions.
✅
Re-Pass after fix
Fixed and verified again
Same QA checklist. Same standards. No shortcuts on re-review.
